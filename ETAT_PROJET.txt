1. IDENTITÉ ET OBJECTIF
--------------------------------------------------------------------------------
LEGAL FLOW est une application web de conformité fiscale, sociale et juridique
pour les entreprises ivoiriennes (DGI, CNPS, CMU/CNAM, FDFP, Code du Travail,
OHADA/SYSCOHADA, Douanes UEMOA). Public : dirigeants, DAF, experts-comptables,
cabinets de gestion.
Promesse : centraliser impôts et taxes, anticiper les échéances avec pénalités,
sécuriser l'entreprise face aux contrôles, révéler les optimisations (CGA, FDFP).
Dossier de démonstration : entreprise BTP (Koffi BTP, Yopougon), régime RSI,
masse salariale ~32,4M FCFA, 18 salariés.

2. STACK TECHNIQUE
--------------------------------------------------------------------------------
- Frontend : React 19 + Vite 6 + TypeScript 5 + Tailwind CSS v4, lucide-react,
  react-markdown (GFM + sanitize), motion, html2pdf.js.
- Backend local/dev : Express 4 (server.ts) + tsx. Build : "vite build" (SPA
  dans dist/) + esbuild de server.ts vers dist/server.cjs.
- Base : Supabase (Postgres + Auth + Storage + pgvector). Client :
  @supabase/supabase-js. Embeddings : @xenova/transformers
  (paraphrase-multilingual-MiniLM-L12-v2, 384 dims).
- LLM : OpenRouter (défaut web : minimax/minimax-m3:free ; WhatsApp :
  dots-studio/dots-3-note-preview:free, voir §9) + circuit breaker opossum,
  cache LRU, timeouts AbortController.
- Hébergement : Firebase Hosting (site statique), Cloud Functions gen1
  nodejs20 (webhook WhatsApp). Monitoring : /metrics (prom-client), logs Pino,
  Sentry (si DSN), Firebase functions:log.
- Sécurité : JWT (requireAuth), rate limit express-rate-limit, validation Zod,
  RLS Supabase, HMAC Meta côté webhook, RGPD (export + suppression compte,
  loi CI 2013-450).
- Tests : Vitest (routeGuard, payrollTaxEngine, obligationEngine,
  complianceScoreEngine). Lint : tsc --noEmit.

5. LOGIQUES MÉTIER CLÉS (valeurs légales codées)
--------------------------------------------------------------------------------
- TVA 18 %, déclaration mensuelle au plus tard le 20 (e-impots.gouv.ci) ;
  retard : +10 % (Art. 160 LPF) + 1 %/mois.
- ITS : retenue employeur reversée au plus tard le 15 ; récidive/retard > 30 j
  : +25 %.
- CNPS : déclaration/paiement au plus tard le 15 (e.cnps.ci) ; 10 % dès J1 +
  1 %/mois ; DISA avant le 30 mars.
- CMU : 1 000 FCFA/salarié/mois (500 + 500) ; quitus CNAM conditionne
  l'attestation CNPS et les marchés publics.
- CGA : abattement 20-25 % BIC ; perte si états financiers hors délai
  (30 avril).
- FDFP : 0,4 % apprentissage + 1,2 % formation continue ; tirage jusqu'à
  0,6 % ; échéance le 15 (+10 %).
- Seuils : Entreprenant ≤ 50M ; RME/RSI 50M–150M ; Réel Normal > 150M FCFA ;
  bascule auto (2 exercices ou +10 %) ; notification avant le 1er février.
- Code du Travail : CDD > 3 mois écrit ; immatriculation CNPS sous 8 jours ;
  SMIG 75 000 FCFA ; amende 50 000–200 000 FCFA/travailleur non déclaré.
- Douanes : BSC OIC obligatoire avant embarquement ; Sydonia/GUCE ; TEC,
  TVA 18 %, PCS 0,8 % ; défaut BSC = 100 % du fret.
- ARF : 3 mois de validité, blocage à la moindre déclaration en retard.
- Contrôle : 10 % retard simple, 25-50 % taxation d'office/mauvaise foi.

7. CHATBOT WEB (AssistantPanel / IAPanel)
--------------------------------------------------------------------------------
- IAPanel n'est qu'un alias d'AssistantPanel (panneau latéral + mode plein
  écran, Markdown GFM sanitisé, effets sonores, citations RAG).
- Fonctionnement : réponse d'abord locale (mots-clés échéances/TVA/retard/

  POST /api/chat (serveur Express) ; persistance optionnelle remontée à App
  vers chatbot_conversations (rechargée à la reconnexion).
- Serveur /api/chat (server.ts, protégé JWT + rate limit + Zod) : recherche
  RAG (pgvector match_documents, repli SQL ilike, repli corpus local),
  prompt système anti-hallucination (interdiction d'inventer, citations
  obligatoires, aveu de limite), appel OpenRouter via breaker, sinon réponse
  experte déterministe (9 thèmes : tva, cnps, cmu, cga, seuil, fdfp,
  embauche, douane, arf + réponse générique). Cache LRU + /api/rag/search.
- État actuel : le chatbot web dépend du serveur Express LOCAL (:3000, non
  déployé sur Firebase) ; en ligne (Hosting statique seul), seul le fallback
  local du panneau répond.

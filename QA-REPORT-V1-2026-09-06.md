7. ANOMALIES VISUELLES (V1.1 — 2026-09-06 ~13h15)
================================================================

Contexte : l'utilisateur a signalé une page d'accueil blanche malgré Sidebar + Topbar
affichées. Inspection DOM via browser_navigate + browser_console (playwright local).

[7.1] BUG-V1-07 (P0) — <main> VIDE quand activePage === 'landing' ET utilisateur connecté
    Fichier  : src/App.tsx
    Lignes   : 106 (init useState) + 762-769 (gestion 'landing' dans guard public)
    Symptôme : Sidebar (4 boutons) + Topbar (H1 "Accueil") s'affichent, mais <main>
               ne contient aucun enfant. L'utilisateur atterrit sur un écran blanc.
    Cause   :
      - useState initial : activePage = 'landing' (App.tsx:106)
      - Le seul rendu de 'landing' se trouve dans le guard public
          if (useRealAuth && !authUserId) { ... activePage === 'landing' -> <LandingPage /> }
        (App.tsx:758-771)
      - Une fois l'utilisateur authentifié, ce guard ne s'applique plus, mais
        activePage peut rester à 'landing' (état initial, ou après redirection
        depuis la landing publique).
      - Aucun case 'landing' n'existe dans le bloc <main> post-connexion.
    Preuves DOM (Playwright local) :
      - document.querySelector('main')?.innerHTML.length = 0
      - document.getElementById('pageAccueil') = null (le composant n'est jamais monté)
      - document.querySelectorAll('h2').length = 0 (le hero "Bienvenue sur Legal Flow" absent)
      - localStorage / sessionStorage / cookies = tous vides (session portée par Supabase côté backend)
    Fix recommandé (3 options) :
      A) Minimal : ajouter dans <main> après les autres cas :
         {activePage === 'landing' && <AccueilPage onNavigate={handleNavigate} />}
      B) Plus propre : forcer routeAfterLogin(role, statut) dès qu'on a un dbProfile
         (effet useEffect sur authUserId/dbProfile).
      C) Garde en miroir : si connecté ET activePage === 'landing', rediriger
         vers routeAfterLogin().
    Effort : Faible (A) / Faible (B) / Faible (C).

[7.2] BUG-V1-08 (P2 UX) — pageTitles.landing et pageTitles.accueil identiques
    Fichier  : src/App.tsx
    Lignes   : 516 + 521 (pageTitles map)
    Constat  :
      landing: 'Accueil',
      accueil: 'Accueil',
    Impact  : la Topbar affiche "Accueil" qu'on soit sur la landing publique OU
              sur la page d'accueil connectée. Confusion pour le QA et l'utilisateur.
    Fix     : landing -> 'Bienvenue' ou 'Portail public' OU accueil -> 'Mon tableau de bord'.
    Effort  : Trivial.

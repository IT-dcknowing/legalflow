  Débit : 30 req/min/IP (429 au-delà).
  Handshake : {"jsonrpc":"2.0","id":1,"method":"initialize",
    "params":{"protocolVersion":"2025-06-18","capabilities":{},
    "clientInfo":{"name":"dc-intelligence","version":"x.y"}}}
    → serverInfo { name: "legalflow", version: "1.0.0" }.
  Puis : tools/list → tools/call. Réponses : { content:[{type:"text",text:"<JSON>"}] }.
  Config type : { "mcpServers": { "legalflow": { "url": "<base>/mcp",
    "headers": { "Authorization": "Bearer <MCP_TOKEN>" } } } }
  Clients stdio : pont npx -y mcp-remote <url> --header "Authorization: Bearer <TOKEN>".
